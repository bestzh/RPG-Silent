## 玩家流程

- 靠近本职业导师或铁匠按交互键，在“任务”页接取、追踪、提交。原技能、转职、强化、宝石服务仍在“成长服务”页。
- J 或 HUD“任务”按钮打开任务手札，查看全部、进行中、已提交任务及目标、奖励、前置条件、交付地点。一次追踪一个任务；右侧 HUD 显示进度，达成后提示回城。
- 击杀 / 通关只从接取后计数，可跨多次副本累计；只匹配任务指定副本，不限制难度。怪物死亡通过副本服务已登记的目标推进，重复死亡通知不会重复计数；失败不算通关，已取得的击杀保留。
- 学习、等级、转职按当前成长检查。开局仍只有普攻，任务不会自动教技能。职业初试承认已有技能；进阶试炼须先转职，再完成接取后的洞窟通关。
- 材料任务要求背包中的现有材料，提交成功时消耗，待领取页不计入。任务完成不会自动发奖励，必须回到对应 NPC。
- 奖励只领一次；提交追踪任务后自动追踪另一项未提交任务，全部完成后清空追踪。

## 保存与失败恢复

v9 新增 `QuestJournalData`：逐任务 ID、计数数组、已领奖标记、追踪 ID。v1–v8 迁移为空任务日志，已有职业、技能、装备、强化、宝石、锁定与配装仍保留。未知任务、错误职业、非法计数或断裂的前置记录不会静默丢弃，继续游戏会报告资源 / 记录不可用并保留原文件。

接取、追踪、交付材料、奖励与“已领取”标记先构建完整候选记录，原子保存成功后才更改内存。重复点击和继续游戏不会重新发奖。满包奖励进入持久化待领取；背包和待领取均无法容纳时，整个提交失败，材料不扣。

已经发生的击杀 / 通关事件保留在内存；写盘失败显示现有存档错误提示，可通过菜单重试保存。重试保存不会重新计数。关闭游戏前仍须保存成功，不能承诺断电后恢复尚未写盘的事件。
