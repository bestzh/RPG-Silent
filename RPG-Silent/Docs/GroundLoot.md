# 地面掉落列表、对比与离开提醒

更新日期：2026-10-28。对应后续总清单 02，复用现有地面物品、品质光柱、字体和输入系统，无外部资源或新持久数据。

按 L 或 HUD“附近掉落”打开列表，上／下方向键切换目标，鼠标选择物品并查看属性；点击“拾取所选”，或按实际交互键／Enter 手动拾取。列表八项一页，只列出 2.4 米内无遮挡的物品。关闭列表后也能用方向键切换地面目标并手动拾取。

密集掉落只显示当前目标的世界名称，光柱与模型保留。六档品质门槛仅影响列表与名称显示，不删除、分解或自动拾取，降低门槛可重新选择。装备详情比较当前相应防具槽或使用中的武器，数值包含原始词条、强化和宝石，并明确为单件对比。金币与经验保持原吸附逻辑。

列表按钮与键盘确认绑定最后实际呈现的目标；目标消失、距离变化、遮挡、满包或保存失败时保留地面物品，不改领另一件。L、ESC 或关闭按钮返回游戏。其他菜单、加载、死亡或结算产生输入阻挡时自动关闭，并保留其他阻挡。

副本中仍有传说／神话物品时，返回主城与再次挑战都先显示放弃确认，包含玩家丢弃物品且不受品质筛选影响。取消或 ESC 保留副本；确认期间高品质物品集合变化时需重新核对。最终离开仍需通过原有挑战奖励和角色保存检查。

实现位于 `PlayerLootInteraction.List.cs`、`MainUI.Loot.cs`、`DungeonRunService.Loot.cs` 与 `DungeonUI`。共享 Canvas 覆盖辅助方法兼容原 HUD 的 100×100 根节点，不改动旧 HUD 布局。初次视觉检查发现面板按小根节点缩放，已修复并增加实际屏幕尺寸断言；缺字的三角标记改为“选中”文字。
