# V5 UI 实施记录

范围：将 `Docs/UIDesign/2026-10-29-functional-v5` 的 84 个页面/关键状态接入现有 Unity uGUI。84 张图对应现有 UI 根、子页面、数据状态与弹窗，并非新增 84 个独立菜单。

## 验收约束

- 保留 `UIBase → UIManager → Addressables` 生命周期及 VContainer 注入；视图调用已有业务服务，不建立第二套角色、物品或任务状态。
- 静态控件、弹窗、子页面、动态列表条目均有可编辑预制体；运行时只绑定、填数据、切换状态及实例化预制体模板。
- 分辨率适配全部保存在预制体：Canvas Scaler、RectTransform 锚点/边距和原生 Layout Group / Content Size Fitter。移除视图按屏幕尺寸计算位置、大小或缩放的代码。
- 根页面、页头、正文、操作区、弹窗和模板分组；使用 `Button_…`、`Text_…`、`Image_…`、`RawImage_…`、`ScrollView_…`、`Content_…` 等明确名称。引用以序列化组件引用保存，重命名不破坏业务接线。
- 背包常驻 5 件防具饰品和 2 把武器，显示名称、强化、空槽与当前/备用；当前穿戴与试穿分开，比较接入已有套装/强化/词条/宝石计算。
- 技能 10 个位置与副本 6 模式直接点选；仓库、回购、专精、故事、长期挑战及保存失败状态接入现有事务与限制。
- 验证 1920×1080、1280×720、1440×900、1024×768、2560×1080；检查点击、滚动、键盘、Esc 层级、重复开关和场景切换。

## 实施顺序

1. 记录现有修改和预制体基线；确认其他聊天释放编辑器，避免中断成长经济验证。
2. 将现有静态控件物化到预制体，建立序列化引用与列表模板；保留原 Addressable key / GUID。
3. 按 V5 组织所有根页面/子页/弹窗，迁移现有事件接线；优先完成背包的已穿戴清单与试穿对比。
4. 移除运行时布局/缩放代码，完成 Canvas、锚点、布局组件及命名审计。
5. 编译、EditMode、隔离存档运行检查和多尺寸截图；修复问题后交付完整预制体清单与接线说明。
