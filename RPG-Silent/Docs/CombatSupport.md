# 战斗补给、状态与单机复活

更新：2026-10-28。复用项目已有药瓶图标、治疗 / 增益特效、攻击配置、主城铁匠、背包及副本结算界面。

## 玩家操作

- 铁匠的“战斗补给”页可购买 1 瓶或 5 瓶药品，满包转入待领取。副本普通怪物有 30% 概率掉落一瓶，首领必掉两瓶；药品需要靠近按交互键 E 手动拾取。金币 / 经验维持原有吸附行为。
- B 打开背包，在“材料药品”分类选择药品，绑定三个快捷槽。默认 Q 生命、R 能量、F 护体，也可将净化药剂替换到任意槽。新角色不赠送药品，仍只有普攻。
- 战斗 HUD 显示快捷键、数量与冷却，按键或显示鼠标后点击药品槽使用。打开背包 / 对话 / 其他阻挡操作的界面、死亡和武器过渡时不能使用。
- 全药品共享 8 秒冷却。换槽、重新打开界面、换场景或读档不会重置；背包详情实时更新剩余时间。冷却使用本机 UTC 截止时间，离线也会流逝，不是服务器防作弊计时。

| 药品 | 金币 / 瓶 | 效果 |
| --- | ---: | --- |
| 生命药剂 | 25 | 恢复 80 生命，不超过上限；满血不消耗 |
| 能量药剂 | 30 | 恢复 60 能量，不超过上限；满能量不消耗 |
| 护体药剂 | 40 | 副本中获得 12 秒护体，额外减伤 20%；主城不可使用 |
| 净化药剂 | 30 | 清除灼烧与迟缓，保留护体；没有异常状态时不消耗 |

## 状态与死亡

- HUD 显示当前护体、灼烧、迟缓的效果与剩余时间。同种状态刷新时不叠加，灼烧刷新不会推迟伤害计时。
- 现有火球与洞窟首领爆发攻击施加灼烧（5 秒，每秒 3 点）；冰霜新星与洞窟水晶领域施加迟缓（6 秒，移动减速 30%）。玩家和敌人都接入状态容器；敌人的导航速度也受迟缓影响。
- 护体先按比例降低伤害，之后沿用现有装备减伤与取整。灼烧对玩家使用持续伤害通路，不会每秒打断技能，但致死仍触发真实死亡状态与动画。
- 死亡、结算与场景重置会清除临时状态。主城拒绝战斗状态。临时增益 / 异常状态本身不写入存档。
- 失败结算提供“复活并重试”和“复活回主城”。目的场景加载成功后才恢复生命、控制与物理；保留已拾取物品和药品冷却。离开前保存失败会留在结算界面，可以处理存储问题后重试。

## 数据与实现

`ConsumableLoadoutData` 保存三个物品 ID 和共享冷却截止时间，存档版本为 v10；v1–v9 兼容路径默认初始化快捷栏及零冷却，不赠送物品。药品与材料一样可堆叠，没有装备实例 ID、词条、强化等级或宝石。

购买与使用先在副本数据上保存，成功后才扣金币 / 数量、应用效果；写盘失败没有扣费、消耗或冷却变更。拾取继续复用现有地面战利品事务，保存失败会保留掉落。

主要实现：`PlayerConsumableProgress`、`PlayerConsumableActions`、`CombatStatusDefinition/State/Controller`，以及 `MainUI.Combat`、`InventoryUI.Consumables`、`TownNpcUI.Supplies`。配置位于 `Resources/Items/potion-*`、`Resources/CombatStatuses` 和现有副本掉落表。未增加包或下载新美术资源。
