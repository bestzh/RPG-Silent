# 主城人口、近距离传送门与任务扩展

2026-10-28。继续使用项目已有模型、动画、传送门特效、字体、材料和副本；没有下载资源或加入联机。

## 游玩入口

- 主城出生广场右侧约 8 米即可进入传送门，仍可选择森林、晶窟和训练场。出生点不在触发范围内；退出界面后需要离开再走入才会重新打开。
- 广场左侧的「广场执事 · 阿登」提供初入主城、城防后续和限时挑战委托。
- 市集的「商人 · 罗莎」提供邻里问候和材料交付支线。
- 右前方的「探险家 · 米拉」提供宝箱、隐藏支路、精英猎杀和首领试炼委托。
- 靠近并面向 NPC 按 E 交谈。头顶及小地图的 `!` 表示可接取，`?` 表示目标达成、可提交。按 J 打开任务手札，可同时按任务状态和主线／支线／职业／特殊类别筛选。
- 任务目标完成后必须返回对应 NPC 提交，才会获得金币、经验和配置的材料奖励。现有导师学习、转职和铁匠成长／补给服务继续保留。

## 主城人口

主城现在有 17 位人物：原有 3 位导师和 1 位铁匠、3 位新委托 NPC、10 位沿街活动的居民与巡逻者。新居民使用 PolygonFantasyKingdom 已有的农民、商人、士兵、牧师、僧侣、酒馆角色模型，包含男女模型。

`TownResident` 使用现有主城 NavMesh（agent type 0），按 3 组手工路线行走，到点停留 2–5 秒。靠近玩家 2.2 米时停下并转向玩家；路线不通或长时间受阻时停止并尝试后续路点。没有战斗控制器、敌方阵营或任务奖励掉落。主城仍禁止玩家攻击。

男女分别使用已有 Relax-Walk-Slow 和 Relax-Walk-Slow-Female，停留使用 Relax-Idle；新建控制器仅组织现有循环动画。居民禁用这些共享动画中仅供玩家使用的脚步事件，不更改原 FBX 导入设置。

传送门完整父节点一起移动，保留原模型、特效和 portalId 101。传送门节点从 `(217.05, -22.09, -85.43)` 移至 `(8.00, 1.39, 4.00)`；将光环抬至地面以上并朝向出生广场，缩小触发体，避免路过导师或刚出生就打开传送界面。

## 进度与保存规则

- 扩展既有 `PlayerProgressService` 与 `QuestDefinition`，未新增全局任务管理器或改变 v10 存档格式。枚举新值只追加，原有序号、任务 ID、目标数组和 `.meta` GUID 保留。
- 对话目标只在实际有效交谈后计数；错误职业导师、异场景、过远或死亡状态不能推进拜访。重复交谈不超过目标上限。
- 宝箱和隐藏支路来自实际成功激活的 `ExplorationNode`。未接取的历史行为不会追溯计数，已用节点不能重复增加进度。
- 精英计数来自副本服务已登记且去重的非 Boss 精英死亡。限时与首领试炼计数来自对应模式成功结算；普通通关、超时和失败不会获得相应特殊目标进度。
- 材料提交、奖励和已领奖标记沿用原子保存。写盘失败时不会部分扣材料或发奖励；奖励满包进入既有待领取机制。实际已发生的探索事件在保存失败时保留于内存，重试保存不会重新计数。
- 原有任务、技能、武器、防具、强化、配装与角色保存逻辑继续共用同一份记录。未成功写入磁盘的事件仍不能保证在退出进程或断电后恢复。
