## 目标锁定与战斗镜头（2026-10-28）

- 鼠标中键锁定 / 解除，滚轮或 `[` / `]` 在画面内可见敌人之间切换。未锁定时继续鼠标转身、WASD 移动；锁定时朝向目标，WASD 用于进退和侧移。弓箭 / 法杖的弹体与射线瞄准锁定点，命中仍由实际射线 / 弹体碰撞决定，不穿墙、不追踪已经发射的弹体。
- 获取距离 24 米，解除距离 30 米；主城、死亡、禁用、菜单阻挡和解锁光标会清除锁定。遮挡持续 0.45 秒后解除；遮挡期间停止锁定瞄准辅助。
- `EnemyController.ActiveEnemies` 按启用 / 禁用 / 销毁维护敌人集合，选目标时按范围、屏幕位置和两条遮挡射线筛选。森林实测附近有 329 个碰撞体，固定容量的环境重叠扫描会漏掉 Boss，因此改用敌人集合，避免环境密度影响候选目标。
- `CameraControl` 复用 Cinemachine 第三人称相机：锁定时平滑偏肩、随目标距离小幅拉远；避障半径 0.22 米，进入碰撞立即收近、离开碰撞平滑恢复。解除锁定平滑过渡后恢复直接鼠标跟随，大距离传送通知 Cinemachine 更新目标位置。
- HUD 显示锁定标记、目标信息、当前防御 / 反击提示和实际绑定键。锁定与防御、前后目标共四个按键加入控制设置的滚动列表；沿用现有按键序列化格式，不修改角色存档格式。

## 闪避、防御与反击（2026-10-28）

- 轻按 Shift 仍是翻滚，按住仍是冲刺。战斗翻滚消耗 10 点现有能量；主城翻滚保留移动用途且不消耗能量。有效躲避窗口为动作开始后 0.06–0.36 秒，起手和收招仍可受击；0.06–0.18 秒内实际躲过攻击触发精准闪避，每次翻滚只触发一次。
- 按住右键防御，可低速侧移。正前方 120° 内的近战 / 射线 / 弹体攻击减伤 80%，每击消耗 `clamp(8 + 原始伤害 × 0.4, 8, 40)` 能量；防御期间暂停自然能量恢复。背后攻击与地面范围伤害不能格挡，已有持续伤害不受闪避 / 格挡影响。
- 举起防御后的 0.18 秒可精准格挡一次近战攻击，免伤并恢复 8 能量；精准窗口之间至少间隔 0.5 秒。普通敌人会被打断，Boss 和霸体动作保留自身状态，转阶段不被打断。
- 精准格挡 / 闪避提供 2 秒反击机会，下一段普攻伤害乘 1.5 并消耗机会；不叠加次数，不自动出招。能量不足时破防，承受该次伤害，0.8 秒后才可重新防御，且必须重新按下防御键。
- 防御消耗、免伤与异常状态在 `AttackExecutor.ApplyDamage` 中统一处理：同一攻击上下文只处理一次，躲避 / 格挡不会附加攻击携带的状态；弹体使用实际入射方向判断正背面。主动攻击、技能、翻滚、跳跃、受伤、菜单、禁用与切场景均有明确退出 / 清理路径。
- 单手武器、双手重剑、弓、法杖分别使用现有 Humanoid 格挡、受击、破防动作，共 12 个独立片段位于 `Assets/Combat/PlayerDefense`。源 FBX 不变；沿用现有金属音效与 Sounds 混音组，男女模型共用动作，没有下载或引入外部资源。

新增主要实现：`PlayerTargetLock`、`PlayerDefense`、`DefenseRules`、`GuardState`、`MainUI.Targeting`。验证脚本与证据使用 `Tools/Validation/LockDefense*`；运行存档隔离在 `Temp/LockDefenseRuntime-20261028`。

## 操作与时序

- 保留鼠标转身、WASD 移动、左键普攻和现有技能快捷键。剑与重剑保留三段普攻，弓和法杖保留单次射击 / 施法。
- 普攻和技能共用 0.3 秒输入缓存，只保留最后一次有效意图；不会积累成自动连招。输入太早而过期时不会在动作结束后补放。
- 普攻命中窗口结束后才能衔接下一段或技能，末段和单发姿态重新普攻至少等到动作进度 90%。技能效果结算后，在动作进度 80% 开放技能接技能、技能接普攻。
- 技能正式开始才消耗能量并进入冷却；缓存、空槽、能量不足、未学会和未就绪的技能不会扣费。施法受伤或主动翻滚中断仍保留已经消耗的能量与冷却，中断前尚未释放的攻击不会迟到结算。
- 受伤、死亡、翻滚、跳跃、关闭战斗权限、切场景、禁用角色、菜单拦截输入与解锁鼠标均清除待执行意图。主城继续收武器并禁止攻击。

关键实现：`CombatActionBuffer`、`PlayerController.Combat`、`AttackState`、`PlayerSkillController`。技能逻辑沿用原 `AttackExecutor` 上下文防止重复伤害；动作切换不撤销已经发射的合法弹体，死亡 / 场景边界和 Boss 转阶段会使旧战斗上下文失效。

## 技能动作与受击反馈

21 个职业技能接入六种现有动作变体：单手斩、双手重斩、弓箭、法杖施法、双手范围施法、短刃突击。素材来自 `ExplosiveLLC/RPG Character Mecanim Animation Pack`，独立片段及 `AnimationData` 放在 `Assets/Combat/PlayerSkills`；没有修改源 FBX。现有男女模型共用 Humanoid 动画。

技能通过 `AtAnimationTime` 在配置的动作进度释放，当前默认 45%，不再在按键瞬间完成伤害。新枚举追加在旧值后，技能稳定 ID 和存档 v10 格式不变。动作时长、释放时机和冷却仍可在对应资产中调整。

六种敌人预制体接入 `EnemyHitFeedback`：实际伤害飘字、命中闪色、空间音效，以及“打断 / 霸体 / 破绽 / 击败”反馈。硬直只短暂停顿受击敌人的 Animator 约 45 毫秒，不改变全局时间；持续伤害不反复触发硬直。每个敌人复用一个文字对象和 AudioSource，通过 MaterialPropertyBlock 闪色，不实例化材质。禁用时恢复动画速度、材质属性并停止声音。

字体使用 LongCang，音效使用现有 `Item_Metal_Sword_1.wav` 并接入 Sounds 混音组；模型、原命中特效和死亡特效沿用现有配置。
