# 分步骤新手引导

更新日期：2026-10-29，对应后续总清单 11。新角色在 HUD 右下角显示当前待完成步骤，沿用现有角色、场景、NPC 与按键系统。

## 操作与顺序

按 Ctrl 显示鼠标，可查看全部步骤或跳过。跳过后仍可通过 HUD 的“操作 / 职业被动 → 分步骤引导 / 回看”查看说明并继续。ESC 关闭回看；背包、NPC、掉落、设置等菜单打开时隐藏引导，关闭后恢复。教学没有输入阻挡、奖励或资源补偿。

| 步骤 | 完成依据 |
| --- | --- |
| 移动 | 使用实际移动输入行走约 3 米，传送不计入 |
| 接取任务 | NPC 接取事务成功 |
| 装备或切换武器 | 武器实际交接，槽位或当前武器发生变化 |
| 进入副本 | 非训练副本成功初始化 |
| 普攻 | 普攻动画进入有效攻击窗口，主城禁攻不计入 |
| 闪避 | 翻滚动画和能量检查通过 |
| 防御 | 实际进入防御状态 |
| 手动拾取 | 玩家交互拾取地面物品成功，直接发货和金币经验吸附不计入 |
| 返回主城 | 进入副本后，角色在主城恢复 |
| 交付任务 | NPC 交付事务成功 |
| 整理背包 | 点击品质、等级、类型或获得排序 |
| 学习技能 | 导师学习或升级技能的事务成功 |
| 强化 | 武器或防具强化事务成功 |
| 仓库 | 存入仓库事务成功，取出不替代存入教学 |

允许提前完成后面的步骤；当前提示始终展示最早的未完成项。回看有两页步骤列表，不改变完成状态。跳过期间不会积累未完成的移动距离，重新启用后重新计步。移动、攻击、闪避、防御、武器切换、交互与掉落列表按当前实际绑定显示；B、J、Ctrl 是现有固定快捷键。

主城保持禁战。新角色仍仅有普攻，学习技能须满足原导师、职业、等级与金币条件；强化和仓库保留原费用与保护规则。传送门为走入范围自动打开列表；通关或倒下后可在结算页返回主城，提前退出可先返回主菜单再继续角色。

## 存档与失败处理

存档升级至 v15，兼容 v1–v14。旧角色默认关闭教学，不强制重做；新角色启用独立的 14 位进度记录。跳过、继续和已完成状态按角色保存，不重置其他角色或资源。

学习、强化、武器交接、任务接交和仓库存入将教学进度放入同一候选快照，写盘失败时不完成步骤、不扣费或移动物品。已经发生的行走、攻击等动作若写盘失败，会保留内存进度并由正常保存重试；手动物品拾取先完成原有原子事务，再记录教学。跳过或继续必须保存成功才改变启用状态。
