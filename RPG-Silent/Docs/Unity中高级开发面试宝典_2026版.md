### Q001 struct 和 class 在 Unity 中如何选择？

| 维度 | 内容 |
|------|------|
| **考察点** | 值类型、引用类型、GC |
| **标准答案** | 数据小、不可变、按值传递且无身份语义时用 struct；有生命周期、需多态或共享引用时用 class。大 struct 频繁拷贝的成本可能超过引用类型的 GC 开销，需按实际 profiling 验证。 |
| **原理解析** | struct 复制值，class 复制引用。 |
| **项目实战** | DamageInfo 可用 struct，Controller 用 class。 |
| **常见错误** | 为了避 GC 滥用大 struct。 |
| **面试追问** | readonly struct 有什么用？ |
| **一句话总结** | 按语义和拷贝成本选。 |
