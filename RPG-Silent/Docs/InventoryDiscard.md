# 背包丢弃与拾回

更新日期：2026-10-28。原背包仅有出售、分解，没有丢弃入口和处理逻辑。本次补齐丢到脚边的流程，全部复用项目现有物品、模型、字体和品质发光资源。

## 操作与规则

按 B 打开背包，选择物品后点击右侧“丢弃物品”。确认窗支持输入数量、加减、全部和取消；装备一次仅处理选中的独立实例。确认后，物品放在角色脚边，关闭背包后靠近按交互键（默认 E）拾回。

- 地面物品不存档，离开场景或退出游戏后消失。确认窗明确显示这一点。
- 已穿戴防具、两个武器槽中的装备和锁定装备不能丢弃；先卸下／移出槽位或解锁。
- 待领取物品必须先领取。批量分解和整套试穿期间禁用丢弃。
- 丢弃不获得金币、经验或分解材料。材料、药品可丢弃部分或全部数量。
- 装备保留实例编号、品质、词条、强化和镶嵌宝石；同名另一件不受影响。
- 取消或关闭背包不消耗物品。确认期间物品状态变化会取消旧确认。
- 拾回时背包满，物品继续留在地上；腾出空间后可重试。
- 主城、森林、水晶洞窟和训练场均支持；主城禁战规则不变。

## 实现与保存

`PlayerInventoryDiscard.cs` 复用 `CommitInventory` 保存事务。确认绑定精确实例／物品堆及数量、强化、词条等当前数据；不自动解析为同名另一件。角色状态和脚下地面通过验证后，先准备未激活的 `WorldLootPickup`，成功保存背包扣减后才启用拾取。保存失败保留原背包并销毁未发布物体；无地面时不创建悬空掉落。

`InventoryUI.Discard.cs` 构建确认窗口并校验数量，接入原背包生命周期和预览刷新。移除试穿物品后自动恢复当前外观，男女共用同一处理。`DungeonRunService.RemainingDrops` 改为统计当前副本场景的活跃掉落，使结算离开提示包括玩家丢下的物品；原敌人／宝箱奖励计数仍只订阅原战利品，避免重复丢弃和拾回刷结算数值。

没有新增存档字段，仍为 v11；沿用现有旧档迁移和原子保存。
