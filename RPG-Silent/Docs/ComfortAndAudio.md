# 音效、设置与操作舒适度

对应后续开发总清单模块 13。2026-10-29 编辑器功能验收完成。当前实现以 Unity 6000.0.66f2、现有资源和全局 VContainer 生命周期为基础；最新独立客户端的验证归模块 16。

## 行为与实现

- `GameAudioService` 统一播放菜单、挥击、敌我受击、格挡、手动拾取、货币吸附和任务交付声音。任务与掉落只在事务成功后发声；重复领取的早退路径不再发声。
- 固定 12 个短音效声部、两个音乐声部和一个环境声声部；同类音效有最短间隔，满池复用最旧声部，并按同时播放数量留出混音余量。角色原有声音在共享服务不可用时复用单个 AudioSource，不使用无限叠加的 PlayOneShot。
- 菜单／主城使用现有《Suntail - Mild Flight》，探索使用 Guitar-Gentle，敌人实际警戒后转入战斗配乐；音乐用 1.5 秒等功率交叉渐变。主城鸟鸣、林地风声和洞窟气泡声来自已有素材。切场景清除短音效；菜单降低背景声。
- 音频配置位于 `Assets/Resources/Audio/Presentation.asset`。短素材按整段 RMS 校准，音乐／环境长素材抽样；峰值受限。八类短音效中七类目标 RMS 为 0.020，挥击约为 0.014，详细结果见 `Tools/Validation/ComfortAudioLevels.json`。这属于工程响度校准，仍允许后续实际游玩调整配器和主观音色。
- 总音量只在 AudioListener 应用一次，Mixer 主总线保持 0 dB；音乐和效果各自使用原 Mixer 的分组。静音、独立音量和已有旧键兼容保留。
- PC 亮度通过全屏、不接收射线的黑色遮罩实际生效；100% 无遮罩，最低亮度保留 35% 画面，避免无法操作。该设置包含 UI，且不修改项目渲染资源。
- 设置的“恢复默认”为预览；“应用”保存；离开分页或返回会撤销该页未应用修改。控制页的绑定与参数使用相同语义。页脚明确显示这些规则。
- 改键拒绝其他移动分量、战斗动作、技能／药品槽及固定菜单键的冲突，保留原绑定并显示动作名称；Esc 取消。冲刺与闪避共享物理键，从任一按钮修改均同步；交互、掉落确认、HUD 和教学使用当前绑定。
- 游戏页新增伤害数字开关、反馈强度；默认开启数字、反馈 100%。强度控制受击闪色、方向受击提示、职业和旅程短提示；关键导航和危险文字继续显示。数字显隐与正在播放的闪色能立即响应设置，原震屏强度独立控制镜头偏移。
- 鼠标攻击／格挡先检查 UI 射线。装饰用 TopLeftPanel 背景不接收射线，避免全屏 HUD 把普通攻击一起拦截；按钮和弹窗继续接收输入。

## 验证记录

- 全量 EditMode：627/627，通过耗时 63.007 秒，见 `ComfortEditModeResults.json`。
- 设置页面：118 项真实输入检查、五种实际 Game View 尺寸共 42 次布局调查；文字溢出、屏外控件、按钮中心被遮挡均为 0。覆盖四个分页、六项游戏设置、默认预览／撤销／应用、音量和亮度实际变化、改键冲突和取消。
- 游戏内：158 项检查通过，覆盖原生角色创建、改绑后 NPC 对话与任务交付、教学提示、菜单镜头／攻击隔离、原生手动拾取及货币吸附、双图进入与结算回城、真实敌人警戒驱动配乐、音频 DSP 输出、攻击动画释放、敌我受击与格挡音效、伤害数字即时显隐、零反馈恢复原闪色、实际镜头震屏和灵敏度。
- 声音池连续 90 轮八类触发，观察到最多 12 个短音效声部，全局 AudioSource 始终为 15；灵敏度 1／2 对相同输入得到约 0.2°／0.4° 转角。
- 画面补充：17 项检查及 1 次布局调查通过。真实指针选择高画质后 Unity 实际等级变为 2；支持的分辨率、窗口模式请求保存。第二次 Play Mode 启动另有 8 项检查确认画质、画面请求、亮度、音量、控制参数和绑定保持。
- 合计 301 项运行检查、43 次布局调查；正常完整运行与最终重启的 Console 错误／警告为 0。`ComfortAudit.py --complete` 核对通过，证据位于 `Tools/Validation/Comfort*Results.txt`、`Comfort*Layouts.json`、`ComfortAudit.json`、`ComfortRestoredState.json` 和 `ComfortFinalConsole.json`。

Windows 键鼠编辑器验证覆盖 1920×1080、1280×720、1440×900、1024×768、2560×1080。Editor Game View 尺寸由编辑器独立控制，分辨率／全屏的真实独立窗口表现仍需模块 16 验收。此轮未重建客户端，未改变画质资源或渲染管线。

验证使用 `Builds/Validation/ComfortSaves` 隔离目录。真实四份存档、既有场景、预制体、Mixer 资源和项目设置按模块前快照核对；其他聊天的 `Docs/UIDesign` 改动保留。测试修改的 PlayerPrefs 包含原键是否存在，结束后按原状态恢复。测试产生的动态字体缓存单独归档后恢复，不提交为内容变更。

运行中的强制脚本重载曾造成全局容器丢失与音频引用失效，该次日志不作为正常启动证据；后续验证从停止状态完成编译后重新启动。验证夹具也修正了克隆标签识别、同名控件定位、同帧延迟销毁的旧任务按钮、下拉框关闭动画等待、菜单异步打开等待和震屏使用游戏时间的采样条件。拾取夹具位于副本，回城使用受控死亡触发实际结算按钮；这些表示与生命周期检查不能代替模块 14 的实际成长与经济游玩。
