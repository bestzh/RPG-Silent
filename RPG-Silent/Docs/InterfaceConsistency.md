# 界面与交互统一

2026-10-29，后续总清单 12 已完成编辑器功能验收。本轮补全逐页输入、布局与弹窗层级验证，最新 627/627 EditMode、898 项运行检查和 392 次布局调查通过；模块 13–16 与完整客户端交付继续。

## 验证范围

Windows 键盘和鼠标；1920×1080、1280×720、1440×900、1024×768、2560×1080 五组尺寸。通过实际 Game View 固定分辨率运行，使用 Input System 鼠标状态事件和 UI 输入模块派发，点击前检查屏幕射线的首个接收对象。普通键盘步骤经过 PlayerLoop；同帧取消另外使用真实 InputAction 事件验证异步请求竞态，不用按钮回调代替点击。

页面包括主菜单、创建／选择角色、四组设置、HUD、背包及确认层、手札四页、导师／铁匠／仓库／各 NPC 故事、传送、正式副本／长期挑战结算和加载失败。复用现有 UI 与资源，保留用户正在维护的 Docs/UIDesign。

## 已修复

- 设置页固定宽约 1611、高约 823，原来在小窗口越界、部分分页无法收到指针。内容现在按 Canvas 居中缩放，背景遮罩覆盖整个 Canvas；菜单与暂停设置统一处理 Esc，展开的下拉框优先关闭。
- UI 根 Canvas 按 1920×1080 参考尺寸缩放，使用 Expand 保留窄屏与宽屏内容。HUD 十个技能按键标签原来文字过大溢出，现限制字号、关闭换行并放在槽位底部；隐藏原无监听器、会被教学遮挡的旧道具占位按钮，保留真实背包入口。
- HUD 原有 100×100 根节点使多个容器仍按固定 1080 高度定位，较高比例下金币栏会压到副本目标上。边缘容器现在跟随真实 Canvas 尺寸，金币、地图与底部技能栏保持边距；副本目标栏宽 704，并增加金币、经验币和生命／能量条不得与目标栏相交的明确断言。
- 原有头像、属性条和武器栏混用居中／边缘锚点；先保留参考尺寸下的实际位置，统一这些既有组件的左上角锚点，再适配当前 Canvas，避免较高窗口下属性条和武器栏挤在一起。远征按钮排列到目标名称区两侧，并检查保留名称区的边界。
- 普通副本目标框原来为 420×78，目标文字需要约 87 像素；统一为普通／远征或考验／远征加考验三种高度，并调整下方查看结算、额外事件与首领栏位置。
- 搜索框释放焦点后，TMP 会处理同一次取消事件并再次激活；现在同时清除选中对象，首个 Esc 只退出输入，随后才关闭窗口。
- NPC 的待确认故事、重铸和不可逆转职预览现在先取消当前确认，再由下一次返回退出交谈；取消不改剧情、职业、物品或金币。
- 操作／职业被动说明页原来按 Esc 会直接打开暂停菜单，说明仍留在后面；现在说明页与分步骤引导回看都优先关闭当前层。
- 背包、手札或 NPC 预制体尚在加载时，Esc 原来可能误开暂停菜单；现在同时检查交互方持有的请求状态，并关闭未完成请求、释放对应输入阻挡。
- NPC 列表重建会销毁被选中的按钮；原空条件调用不能识别 Unity 的已销毁对象，导致下次背包 Esc 触发 MissingReferenceException。背包和仓库现显式检查对象有效性，保留初始异常堆栈。
- 加载失败页增加 Esc 返回，复用现有返回游戏／安全主菜单逻辑；正在加载的请求继续保留保护。
- 普通训练武器的地面文字原来只有名称，缺少品质；现为不含品质前缀的名称补充品质文字，已有“史诗长弓”等名称保持。六档品质仍使用现有模型、环形边界、不同高度光柱及对应颜色。
