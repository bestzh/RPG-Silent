# RPG-Silent 操作与成长指南

更新：2026-10-29。本文对应当前工作区已有规则。V5 界面正在验收，成长与经济、长时间稳定性及最新 Windows 完整客户端仍未完成最终验证；进度见 [后续开发总清单](后续开发总清单.md)。

## 开始与继续

从开始菜单创建角色，选择剑士、弓手或法师及男女外观，确认后进入主城。浏览职业与外观不会更改已有角色。新角色从普攻开始，技能需要向对应职业导师学习；创建新角色会保留已有角色。

选择角色页可查看各角色等级、保存时间和装备预览，再进入主城继续。游戏中先在暂停菜单保存并返回主菜单，再选择其他角色。每个角色独立保存背包、仓库、技能、职业、任务和成长。

## 默认键鼠操作

改键后以设置页及游戏提示显示的实际绑定为准。

| 操作 | 默认输入 |
| --- | --- |
| 移动、转向 | WASD、移动鼠标 |

| 冲刺／翻滚 | 按住／轻按左 Shift |
| 跳跃 | 空格 |
| 普攻 | 鼠标左键 |
| 重剑／弓蓄力 | 按住左键，松开释放 |
| 防御 | 按住鼠标右键 |
| 锁定／解除目标 | 鼠标中键 |
| 切换锁定目标 | 滚轮，或 `[`／`]` |

## 第一段成长

跟随新手引导和主线拜访主城人物，向本职业导师接取副本任务。在导师的技能研习中查看等级、费用、当前和下一级变化；学习后检查技能位置，也可以直接选择位置装配。角色达到条件后仍在原导师处选择转职分支，确认前可取消。

铁匠提供武器、防具饰品强化、宝石、配方锻造、词条重铸及补给。武器先放进武器槽再强化；强化上限为 +5。材料要放在背包，仓库或待领取中的材料不会自动支取。先核对费用和条件，再确认操作。

从主城传送门选择地图、难度和模式，进入后按目标推进波次、处理机关并击败首领。注意敌人的攻击预警和地面范围，受伤时使用已装配的药品。通关后可继续拾取，再通过结算页回城；主线奖励需要返回对应 NPC 提交。

每个角色可以选择一个专精方向：连武、凝神、坚守，或满足御兽师及召唤技能条件后的驭灵。三级分别需要 Lv.6／12／18，费用为 150／300／450 金币和 2／4／6 枚锻造碎片。重置支付 100 金币，返还投入金币的 80%，材料不返还；重置后重新学习仍需完整投入。

## 掉落、背包与试穿

金币和经验会吸附；装备、材料和药品需要手动拾取。L 打开附近掉落列表，可筛选显示品质、选择物品并查看比较。品质筛选只影响列表显示。满包时先检查待领取或整理空间。

B 打开背包，可按名称搜索，按品质、等级、类别或获得时间排序。选中装备会展示试穿和属性变化，确认穿戴后才更改实际装备；取消试穿恢复当前外观。左侧显示五个防具饰品槽及当前、备用两把武器。整套试穿和配装也须确认后才生效。

重要物品可锁定。出售、分解和丢弃前核对所选实例、数量和保护提示；批量操作会显示确认清单。已穿戴、武器槽、锁定或方案引用的物品按相应保护规则处理，镶嵌宝石装备出售前先拆卸宝石。丢弃物品落在脚边，可以重新拾取；离开场景或退出游戏后消失。

在主城执事处使用角色仓库，容量为 96 格，支持搜索、分类及批量存取。穿戴中或配装方案引用的装备须先处理引用再存入；仓库不跨角色共享。

铁匠补给可选择 1–99 件并核对总价；晶核碎片需要完成材料委托或达到相应好感。误售物品可在本角色的回购页原价取回，保留最近 24 项、最长 48 小时。回购需有金币与容量，逾期记录不再可用。

在背包给药品配置 Q／R／F。药品共用 8 秒冷却；生命和能量已满等不满足使用条件时，检查游戏提示。传说、神话装备的固有效果只由当前武器与实际穿戴提供，同类取最高级；备用武器和试穿不提供效果。完整条件可在装备规则中查看。

## 任务、探索与重玩

J 打开手札，按类别和状态查看、追踪任务，并核对前置条件、章节及交付人物。任务放弃与重新接取会清空相应目标进度；已经获得的物品、历史奖励和剧情选择保留。剧情选择会影响后续支线，好感可开放委托及铁匠补给优惠。成就奖励需要手动领取，图鉴按当前角色记录。

固定副本包含机关、宝箱、隐藏路线和精英事件。传送页还提供随机远征：进入前查看组合与事件，事件奖励有独立领取记录；死亡或重试不会清除已领取标记。已经保存的普通掉落与成长保留，场景中的活动位置不作为读档断点。

首领连战共 6 轮，千层试炼上限 1000 层。清轮保存成功后可以休整、继续或结束；死亡、超时或离开挑战区域会结束尝试。已保存的奖励与最高纪录保留，重新进入从第 1 轮开始。长期挑战不提供普通副本装备掉落；具体倍率、时限与首奖规则以进入前说明为准。

## 保存与设置

暂停菜单可手动保存，返回主菜单和退出前也会保存。保存失败时先保留当前会话，按提示排查后再保存；确认成功后再切换角色或退出。无法读取或版本不兼容的角色文件会保留，损坏主档可以尝试从该角色的有效备份恢复。

设置提供画面、声音、控制与游戏反馈选项。默认值先用于预览，应用后保存；离页会撤销尚未应用的修改。控制设置支持改键并拒绝冲突，冲刺和翻滚继续共用绑定。声音、亮度、伤害数字及反馈强度可按需要调整。

当前仅支持本地单机进度，不包含组队、服务端或云存档。
