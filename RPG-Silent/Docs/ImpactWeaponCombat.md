# 玩家受击与武器差异化

日期：2026-10-28。沿用鼠标转向、WASD 移动、现有输入改键、武器装备、技能、护甲减伤、锁定、防御和副本规则。未增加联机、外部资源、付费包或存档字段。

## 玩家受击

- 四类武器都有前、后、左、右受击动作，以及重击后仰动作；男女角色使用现有 Humanoid 重定向。
- 轻击硬直 0.3 秒，重击 0.65 秒，破防 0.8 秒。硬直期间重复命中仍扣血，但不重新开始硬直；恢复后再提供 0.3 秒硬直保护，保护不免伤。
- 击退根据来袭方向计算，保留重力，并通过现有刚体扫掠检测墙体。平地无障碍时轻击约 0.28 米、重击约 1.12 米；墙体或其他碰撞会缩短距离。
- 受击时关闭当前近战窗口，取消待释放蓄力和可打断技能；重击也会强制打断技能。已发出的合法弹体保留独立上下文。
- 格挡、精准格挡和翻滚无敌先判定；格挡成功不会播放普通受击或击退。破防保留各武器原有破防动画。持续伤害扣血和显示提示，但不造成硬直、击退或镜头震动。
- HUD 显示实际扣血、来袭方向；轻重受击有短促音效和不同幅度的镜头震动，遵循原有“屏幕震动强度”设置。没有修改全局时间缩放。
- 森林 Boss 陨击、连段终结，以及晶窟 Boss 重砸、震荡、爆发被标记为重击，常规攻击保持轻击。

## 四类武器

普攻默认鼠标左键，所有提示读取实际改键。右键防御、中键锁定、轻按 Shift 闪避继续生效。

| 武器 | 操作与效果 |
| --- | --- |
| 单手剑 | 三段快连击，前两段动画速率 1.28，末段 1.12；末段削韧倍率 1.8。完成闪避后 0.65 秒内普攻可追击，伤害 ×1.3、短距离前冲，使用现有奔跑斩击动作。 |
| 重剑 | 点按保持三段连击；从待机/移动起手按住普攻，1.2 秒满蓄力，松开重斩。满蓄力伤害 ×2.4、削韧 ×3，保留重斩收招时间。 |
| 弓 | 点按速射；按住 1 秒满蓄力后松开，伤害最高 ×2.2、箭速最高 ×1.7。使用正前方拉弓/放箭子动画；箭仍受场景碰撞阻挡，不追踪敌人。 |
| 法杖 | 点击续段或按住连续施放三段魔弹；第三发伤害 ×1.4，命中敌人回复 6 能量。每个第三发上下文只回复一次，未命中不回复，松开停止自动续段。 |

蓄力 0.18 秒以内按未蓄力处理，之后线性增长。蓄力本身不扣能量，但暂停自然回能。所有加成在普通攻击创建时快照，不修改共享 AttackProfile；装备品质、强化和现有反击加成继续参与结算。全部六档品质法杖都配置了三段攻击。

防御、闪避、跳跃、有效技能、受击、死亡、回城、禁用玩家、UI 阻挡和输入重建可取消蓄力。普攻松开在状态更新时提交，让同一帧的防御/技能取消优先，避免误出招。近战窗口关闭不受“已经禁用战斗”限制，避免禁用后残留命中框。

## 资源与接入

- `Assets/Combat/PlayerImpact`：28 个复制自现有 ExplosiveLLC 资源包的 Humanoid 动作，清除伤害事件；原始 FBX 未改动。
- `PlayerAnim.controller` 增加受击、蓄力、放箭、重斩和追击状态；`BasicAttackSpeed` 仅影响基础攻击状态，不改变整体 Animator 速度。
- 法杖 Override 使用已有的三个施法动作；弓的 Aiming FBX 含九个方向，明确选择 `-CM` 正前方子动画。
- `RPG-Character.prefab` 已配置 `PlayerHitFeedback` 与现有声音、Sounds 混音组；PlayerRig 和男女职业外观继续继承。
- 攻击效果沿用 AttackExecutor / AttackContext；硬直仍由 HurtState 管理，物理位移仍由 PlayerMotor 管理。
- 可重复执行的资源配置：`Tools/Validation/ImpactWeaponSetup.cs.txt`。无需手动拖拽配置。
