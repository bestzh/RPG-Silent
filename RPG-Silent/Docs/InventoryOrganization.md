# 背包整理与检索

更新日期：2026-10-28。对应《后续开发总清单》模块 01。本轮完成背包的整理、检索与批量出售／丢弃，并验证相关输入、保存和旧档兼容路径。独立 Windows 客户端尚未重新构建；后续地面掉落列表、仓库与回购继续按总清单推进。

## 玩家操作

按 B 打开背包。上方分别提供全部、防具、武器、材料、待领取、药品、宝石分类；材料分类不再混入药品或宝石。名称搜索支持中文、忽略首尾空格和英文大小写，点击“清”恢复列表。

品质、等级、类型、获得四个按钮切换排序，再次点击当前按钮反转方向。排序只改变显示顺序，选择、试穿、穿戴、出售和丢弃始终使用具体实例。详情显示获得时间；装备格显示等级门槛／可装备提示，新物品带“新”字标记。

- 新获得装备、材料、药品和宝石都有新标记。点击查看后保存已读状态；写盘失败则保留新标记并显示失败原因，下次查看可重试。
- 装备记录这次入包的获得时间；一堆材料／药品记录最近补入的时间。重新拾回丢弃物品属于一次新获得，不改变实例、词条、强化或宝石。
- 旧物品没有可靠获得日期，显示“旧物品，时间未知”，不全部标成新物品。按获得时间排序时，未知日期始终排在已知日期之后。
- 领取待领取物品保留原获得时间与新标记，避免领取行为改变原记录。

点击“批量出售”或“批量丢弃”进入多选，再点物品可取消该项。默认选择整堆，分类与搜索后仍保留已经选择的项；“核对清单”列出全部物品、品质、强化、宝石、数量和出售总价。每页最多八项，使用上一页／下一页查看全部内容，通过加减与“全部”调整各堆数量，最后确认一次提交。

- 出售只允许在主城进行；已穿戴防具、两个武器槽中的武器、锁定装备及镶嵌宝石的装备均受保护。
- 丢弃保护已穿戴、两个武器槽及锁定物品；未穿戴的宝石装备可以丢弃，宝石随原实例保留。所有选中物品保存成功后才发布到脚边，可关闭背包后手动按交互键拾回；离开场景或退出游戏后消失。
- 取消确认保留选择，不扣物品或金币。确认期间锁定、强化、数量等发生变化时，旧确认失效；保存失败保留全部物品，不产生可拾取副本。
- ESC 依次退出正在编辑的输入框、顶层确认窗、批量选择／试穿，再关闭背包。关闭确认窗时继续阻挡战斗输入，关闭整个背包后才恢复操作。搜索或数量输入框获得焦点时，输入字母 B 不会关闭背包。

## 实现与兼容

`InventoryQuery` 生成只读显示副本，按实例键稳定排序；不重排背包存储或改写穿戴引用。`ItemStackData` 增加 `acquiredUtcTicks`、`isNew`，深拷贝、奖励、堆叠和待领取搬运均保留相应语义。

存档版本升级为 **v12**。v1–v11 沿原迁移链加载，并将旧物品时间设为未知、新标记设为已读。读取与预检不改写旧文件；保存仍使用现有校验、备份与原子替换。未来版本、无效元数据及不可读文件继续保留原文件。

`PlayerInventoryOrganization` 的批量确认绑定角色、操作类型、精确实例、全部当前物品属性、选择数量和出售价格。任何一项不满足条件就拒绝整笔操作；金币总价用长整数校验上限。丢弃先准备未激活掉落，再一次保存全部背包扣减，成功后才启用掉落。原单件丢弃复用同一提交逻辑。

`InventoryUI.Organization` 构建搜索、排序、多选与分页确认。保留原有整套试穿、配装、分解、强化与药品快捷栏；批量选择期间禁用相冲突的穿戴、单件交易及快捷栏修改。退出或切换场景清理确认状态和输入阻挡。没有新增依赖、外部资源或场景／预制体改动。
