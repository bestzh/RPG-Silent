# 职业联动、探索、挑战与训练场

2026-10-28。沿用项目现有模型、动画、场景、音效、UI 字体与战利品资源；不包含联机。

## 玩家入口

- 主城传送门提供森林、晶窟和独立训练场。副本详情中的“模式”按钮在普通探索、限时挑战、首领试炼之间切换；训练场使用独立场景，不打开主城战斗权限。
- E 交互宝箱、机关、隐藏石碑和精英试炼晶石。脚边存在可拾取物品时优先拾取，再操作机关。宝箱开盖后生成地面战利品，装备 / 材料仍需手动拾取，金币继续吸附。
- HUD 显示生命 / 能量数值、技能冷却秒数；附近地图显示宝箱、机关、精英、敌人、友方召唤物、导师、铁匠和地面物品。地图朝北，玩家箭头随朝向转动；隐藏目标靠近后才显示。
- 按 Ctrl 显示鼠标，点击“操作 / 职业被动”查看当前职业的说明。战斗与交互提示沿用现有输入动作与改键显示。

## 职业与技能

| 职业族系 | 实际规则 |
| --- | --- |
| 剑士、剑圣、狂战士 | 同一目标 4 秒内连续命中 3 次，破防 4 秒；破防期间自身命中伤害 ×1.25、硬直积累 ×1.75。尊重首领转阶段和技能霸体。 |
| 游侠、神射手、刺客 | 从目标背面或首领反击窗口命中，伤害 ×1.5。职业技能标记目标 5 秒，下一次命中消耗标记获得弱点加成。 |
| 法师、萨满、御兽师 | 同一目标 4 秒内命中不同元素的技能，后击伤害 ×1.4，并回复 5 能量；消耗这对元素，不连续重复触发。火球 / 冰霜 / 雷霆分别配置火 / 冰 / 雷，萨满大地震击为土。 |
| 御兽师 | 原“兽灵冲击”课程接入“兽灵召唤”，稳定技能 ID 不变。消耗 30 能量，冷却 25 秒，召唤现有 MeleeGuard 兽灵 20 秒；每级增加 3 秒持续时间与 20% 伤害。最多一只，重召唤替换原兽灵。 |

转职分支继承对应基础职业的被动。被动按实际命中触发；同一个攻击上下文对同一目标最多触发一次联动，持续区域不能靠每次跳伤无限叠加或回能。临时标记不写入存档，切场景 / 重置时清除。

兽灵复用现有 Behavior Designer 树、NavMesh、技能动作与伤害系统，寻找主人附近敌人，无目标时跟随主人。玩家与兽灵互不伤害，兽灵不参与敌人目标锁定、不产出金币 / 经验 / 战利品；死亡、禁战、离场或到期时清除。绿色“友方兽灵”标牌与地图标记区分阵营。

## 两个副本的探索配置

每关提供补给宝箱、机关门后的宝箱、隐藏支路宝箱和一个可选精英伏击事件。开启机关会播放门体移动并解除碰撞与导航障碍。森林隐藏石碑位于封门通道内部，打开后方石壁，通向现有森林侧路；晶窟隐藏支路位于后部大厅侧边。

精英事件生成两只现有敌人，生命 ×2、伤害 ×1.25，基础金币与经验 ×2，并有精英标牌。未开启时不阻碍通关；开启后加入本次清理目标，完成后额外生成事件战利品。宝箱采用本关已有的品质掉落表和光效，不保证高品质。

节点开启状态、秘密发现和精英事件只属于当前副本实例。重试重置，离开不保存地面物品。首领试炼关闭探索交互，只保留强化首领目标。

## 挑战与结算

- 森林限时 5 分钟，晶窟限时 7 分钟。超时不强制退出，仍可清理与拾取，但不给限时额外奖励。
- 首领试炼跳过普通波次，只生成首领，额外生命 ×2、伤害 ×1.25；保留原有阶段机制。
- 限时达成额外奖励基础 120 金币 / 120 经验；首领试炼通关额外奖励基础 180 金币 / 180 经验。乘以所选难度的奖励倍率，普通探索不追加挑战金币。
- 结算显示通关时间、击败目标、探索互动数、实际输出、实际承伤、精准格挡与精准闪避次数，以及已拾取物品和待拾取数量。
- 挑战奖励复用现有原子保存事务；写盘失败时保持待领取，结算可重试，重复领取不重复加钱。待领取时阻止直接离开，以免丢失这次奖励。

计时使用游戏时间；项目现有菜单不暂停世界，打开背包或菜单仍然计时。统计在新一局重置，当前没有历史排行榜、跨局最佳纪录或新的存档版本。

## 训练场

独立 `TrainingGround` 场景复用晶窟环境与导航资源。提供连段 / 技能模式、防御 / 闪避陪练、重置与回城机关；HUD 另有重置和回城按钮。

连段目标按武器适配：剑 / 法杖练习三次末段，弓练习十次命中；有已学技能时追加三次施法，没有技能时提示回主城学习。防御目标为精准格挡和精准闪避各三次。陪练使用实际攻击、格挡与翻滚判定。

训练目标不会死亡或掉落，玩家不会被训练伤害击杀，每五秒恢复生命 / 能量。消耗品在训练中不可使用，避免消耗背包库存。训练不临时解锁技能，也不提供经验、金币或升级收益；学习、转职仍由主城导师负责。

## 实现边界与回归修复

- 保留 v10 存档结构、已有职业 / 技能稳定 ID 与旧角色；新增状态均属于当前场景或战斗。
- 新场景加入现有 Addressables 的 Scene 组，保留启动、主城和双副本的加载地址；未改包依赖和联机配置。
- 森林部分可碰撞苔藓位于 Ignore Raycast 层，原玩家地面遮罩排除了该层。验证复现了站稳但判空中、无法交互的情况；地面查询与玩家预制体现改为包含所有物理层，继续排除自身与触发器，保留坡度限制。
- 兽灵无目标跟随时，原行为树曾每次决策都切回待机并清空导航路径。现在跟随期间暂停行为树的战斗决策，接敌后恢复；4 秒运行补测从 50 次待机 / 追逐交替降为正常的 2 次状态变化，并能走到主人附近。
