# 副本随机变化

2026-10-29 后续总清单 08 编辑器功能验收完成。最新 Windows 客户端、多难度平衡及长期运行仍随阶段 E 验证。

## 进入与规则

在主城传送门选森林或洞窟，把“模式”切换到“随机远征”。进入前展示种子、规则版本、阵型、两种精英特性、可用的额外探索节点、事件条件、奖励及重试规则。“更换组合”只更新预览，确认进入后才替换该角色上一远征。

每个角色保存一个最新组合，含唯一标识、单调序号、地图、难度、正整数种子、规则版本、尝试次数、事件状态和奖励领取标记。种子由固定整数算法生成三类事件／三种阵型／三组特性／三种节点集合，不依赖全局 Unity Random、帧序或 System.Random 实现。

| 内容 | 规则 |
| --- | --- |
| 阵型 | 原阵型、近远轮换、近战前锋；复用地图原出生点与本图近远程预制体，人数不变 |
| 精英 | 每波前两个非首领分配护盾／治疗、狂暴／护盾或治疗／狂暴；首领保留原配置 |
| 可选探索 | 补给箱、精英伏击，或两者均启用 |
| 依赖保护 | 机关、封门宝箱、隐藏支路和隐藏宝箱保留；不会随机关闭机关而留下其依赖奖励 |
| 额外奖励 | 事件成功发放 `80 × 难度数值` 金币和等量经验；简单／普通／困难／噩梦／地狱为 80／160／240／320／400 |
| 普通奖励 | 敌人和探索掉落继续走原拾取与任务记录流程；每次正常重试可重新获得普通掉落 |

主线波次清理完成后，事件尚未结束时不会直接进入通关结算。可在开始或活动过程中明确放弃额外事件，确认后完成普通波次仍可通关；放弃不发事件奖励，已拾取物品保留。确认窗口支持取消与 Esc，恢复原输入状态。

## 三类事件

靠近金色信标使用当前交互键开始。事件开始状态先保存，保存失败不生成目标或敌人，并在目标栏提示重试交互。

| 事件 | 真实完成条件 | 失败条件 |
| --- | --- | --- |
| 护送信标 | 跟随导航信标到达最后路标并清除事件敌人；玩家保持 6 米内，敌人进入 2.5 米时停步 | 120 秒超时、角色死亡、路线失效或移动持续受阻 |
| 守卫据点 | 在 3 米圈内累计驻守 25 秒，击败第 0／12 秒生成的两批守卫；离圈或敌人进圈暂停累计 | 90 秒超时或角色死亡 |
| 追击信使 | 击败沿既定路线绕行三圈撤退的真实精英敌人；普攻／技能、受击中断和状态减速继续使用原战斗管线 | 60 秒超时、信使到达终点或角色死亡 |

额外事件失败不会抹掉普通副本进度。角色死亡仍使本次副本失败；失败后的重试由原出生流程复活。场景卸载停止事件导航、敌人行动、协作组和监听，不留下跨场景目标。

## 保存、重试与重复领取

进入前提交本次尝试；状态包括可开始、活动、完成、失败和放弃。事件完成与奖励领取标记、金币和经验在同一次事务中保存，失败时不先发奖励。目标栏或结算页提供“重试保存”；奖励未保存时不能离开。

同一组合的重试保留种子、规则和领取标记，尝试次数增加，敌人、探索及事件进度重置。退出或读档回主城后可重新进入保存的组合，活动中的位置和驻守时间不作为断点恢复。已经领取的事件奖励不因死亡、重试、重新完成或读档而清除。旧尝试令牌、已结算状态和其他角色的令牌不能再次结算。

v17 兼容 v1–v16；旧角色迁移为空远征记录，保留已有职业、装备、任务、仓库、交易、引导和专精。Windows 1175 的原子保存保护及其独立证据见 [SaveAtomicRecovery.md](SaveAtomicRecovery.md)，不把该局部修复当作模块 15 全部完成。

## 配置与导航

`Assets/Resources/Expeditions/Dungeon1001.asset` 与 `Dungeon1002.asset` 配置原有敌人引用、事件路线、伏击点、两个可选节点标识和现有材质。`ExpeditionAuthoring.Install` 只生成这两份配置，不重写地图、导航、原出生点或预制体。

进入随机模式时验证地图匹配、必需目标、可选节点类型、有限坐标、导航采样、入口到起点、全部路标循环和伏击点的完整路径。配置缺失或路径不完整时给出失败结算与回城途径，不静默生成不可达目标。森林使用入口附近已连通区域，不跨越原有围护结构造成的导航分区。

普通探索、限时挑战、首领试炼及训练入口仍分别使用原流程。随机远征不会同时叠加限时挑战或首领试炼，不向这些模式写入错误的任务达成事件。没有新增模型、动画、贴图、音频、行为树或下载资源。
