## 宝石工坊

在主城靠近铁匠按交互键，打开“宝石工坊”。上方四个配方制作宝石；向下滚动，选择一件背包内的防具或饰品进行镶嵌。每件头部、护甲、靴子、戒指、项链各有一个槽，武器暂不设槽。已穿戴和备用防具均可操作。

| 宝石 | 固定加成 |
| --- | --- |
| 生命晶石 | 生命 +30 |
| 凝神晶石 | 能量 +15 |
| 锋芒晶石 | 伤害 +3% |
| 守护晶石 | 减伤 +2% |

- 每颗制作消耗 150 金币、3 个晶核碎片；宝石在背包“材料”分类堆叠。
- 镶嵌消耗 1 颗宝石和 50 金币；替换也为 50 金币并完整返还旧宝石。
- 拆卸消耗 50 金币并返还宝石。背包满时，制作或返还的宝石进入“待领取”；若待领取也无法存放，整个操作失败，金币、材料和槽位保持不变。
- 只能消耗背包里的材料和宝石，“待领取”须先领取。相同宝石不能重复镶嵌扣费。
- 镶嵌宝石的装备不能出售或分解，需先在铁匠处拆下宝石。
- 宝石只为实际穿戴的那件装备增加属性，不改变外观、不治疗、不被强化倍率放大；备用装备不生效，全身减伤仍封顶 50%。

## 套装

每套包含头部、护甲、靴子、戒指、项链各一件。各阶效果累加：5 件时也享有 2、4 件效果。只统计实际穿戴，不统计背包、待领取、试穿或武器。

| 套装 | 2 件生命 | 4 件能量 | 5 件伤害 |
| --- | ---: | ---: | ---: |
| 旅人 | +20 | +5 | +2% |
| 林卫 | +40 | +10 | +4% |
| 晶辉 | +60 | +15 | +6% |
| 守望 | +80 | +20 | +8% |
| 王权 | +100 | +25 | +10% |
| 赤曜 | +120 | +30 | +12% |

混穿可同时获得不同套装的有效阶数。卸下或换装立即重新计算。套装绑定在现有装备定义上，旧装备也可激活；职业和性别不限制套装。

背包显示宝石、单件强化与宝石贡献、套装件数和各阶激活状态。防具右侧的属性差值表示确认换装后的全身变化，包含失去/获得的套装效果和减伤上限，不能仅按两件装备的基础属性相减。试穿不应用这些数值。
