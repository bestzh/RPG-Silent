# RPG-Silent · 构图研究 V4

2026-10-29。本轮交付 6 个关键页面的概念图与 1 张方向说明，1920 × 1080；并非整套 UI 已完成改版。仅在本目录新增设计文件，未修改游戏代码、Assets、场景或预制体。

## 判断

此前重复使用大面板、三栏和卡片，造成不同页面轮廓相似。换材质、转动纸页和更换手写标题只改变了局部皮肤。这一轮从视觉重心、画面占比和容器层级重新组织界面。

推荐轻史诗奇幻：呼应现有低多边形角色、村镇、林地与晶窟，让场景和人物先被看见；用少量刻面、徽记、弧线、深青底色和旧金焦点表达身份。主中文标题与正文保持清楚。纸本可局部用于信件或任务，金属可局部用于锻造，无需覆盖每个页面。

背包、仓库、商店和设置仍需要规则的网格与对齐。减少外层的大容器，可同时保留定位效率和更开放的页面轮廓。

## 查看

- `index.html`：离线画廊与方向分析；导航、方向键和传送目的地可切换。
- `screens/00-direction.png`：设计判断与布局示意。
- `screens/01-start.png` 至 `06-settings.png`：开始、行囊、技能、远行、战斗、设置六类构图。
- `boards/layout-overview.png`：六张概念图总览。
- `screen-manifest.json`：每张概念图的目的和限制。
- `source-manifest.json`：40 份所用资源的来源和哈希，含模型预览来源。
- `qa-report.json`、`gallery-check.json`：画板、导航、目的地切换、布局间距和键位基线的检查记录。

六张设计已逐张查看。保留 24 格背包、五个防具饰品槽、两个武器位置和十个固定技能位置。技能的装饰弧线不表示前置关系，旅程线不表示无缝世界地图。设计按钮与数值仅供构图评审，除画廊导航和目的地切换外不模拟游戏事务。

## 后续页面如何延展

| 页面类型 | 推荐组织方式 |
|---|---|
| 角色创建、选择 | 大角色加侧边职业或存档列表，保留清楚的选择范围 |
| 仓库、商店 | 规则网格与当前物品的就近对比，不套多重完整窗口 |
| 任务、成就、图鉴 | 章节路径、进度线或收藏陈列；选中后展开详情，复杂正文仍保留水平排版 |
| NPC 交谈 | 人物与场景优先，对话和选项靠近下方，长选项使用清楚的列表 |
| 锻造、强化、镶嵌 | 当前装备为主视觉，材料围绕操作区，属性与费用明确对齐 |
| 结算 | 徽记、结果标题与一行统计形成中心层级，奖励按类型排列 |

上述为延展建议，并未在本轮逐页绘制。正式扩大覆盖时，需要重新核对当前工程已新增的仓库、附近掉落、回购、专精、随机远征、长期挑战、章节任务与引导等功能，完整保留各自入口和状态。

## 素材和边界

参考了当前 `Docs/UnityProjectContext.md`、实际项目截图、角色模型预览、装备槽位枚举和现有技能数据。所用素材直接复用已核实的项目资源，本目录包含可独立浏览的素材副本。

开始与 NPC 页面使用项目背景插图；远行与战斗部分底图含 Synty 资源包示例画面，仅用于界面构图，不表示实际游戏关卡、人物或 Boss。角色大图来自项目职业模型的既有渲染。正式落地应替换为对应游戏场景与角色镜头。

英文标题使用现有 Ortica 字体，许可证随素材保留。中文使用系统 Microsoft YaHei 进行预览，未分发该字体；可随游戏发布的中文正文字体仍待补齐。本轮未新增购买资源，也没有重新导入资源包。
