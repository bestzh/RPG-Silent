# RPG-Silent 全界面设计稿 · 第一版

40张页面与关键状态设计图，以及1张视觉规范图；单张1920 × 1080。

- 打开 `index.html` 按目录浏览，支持上一张、下一张和键盘左右方向键。
- `screens/`：全部原尺寸PNG。
- `boards/hero-overview.png`：六张代表页面。
- `boards/all-pages-overview.png`：全部40张总览。
- `boards/board-1.png` 至 `board-5.png`：每组8张设计图。
- `RESOURCE_AUDIT.md`：现有资源来源、需要补齐的字体与建议图标。
- `screen-manifest.json`：每页功能、主要设计意图与源码依据。
- `source-manifest.json`：素材源路径、GUID与文件哈希。

## 统一方向

深岩灰承托游戏画面，暖金表示当前选择，羊皮纸承载任务阅读；薄荷绿表示收益，陶红表示危险操作。标题使用项目Long Cang，正文使用系统雅黑作可读性预览。

主体安全边距64px，8px间距基准，主要点击区48–76px；阅读字号22–26px，辅助字号18–20px，密集列表保留16px下限。正式版本应在16:9与常用分辨率下检查缩放、长文本和键位长度。

本地浏览稿用于观察布局、页面切换、职业/性别切换和视觉状态。旋转、缩放、背包管理、购买、强化等游戏行为在此稿中仅呈现设计效果。

## 覆盖范围

1. 开始菜单、创建角色、选择角色。
2. 主城HUD、Boss战HUD、训练场、教学、世界提示。
3. 背包、批量分解、待领取、药品绑定、三个配装方案、丢弃确认。
4. 任务、成就、图鉴。
5. 导师、转职、武器强化、防具强化、宝石制作与镶嵌、NPC委托、故事选择、补给、配方、重铸。
6. 森林、晶窟、训练场传送选择，通关与死亡结算。
7. 暂停、屏幕/声音/控制/游戏设置、加载与失败恢复。

## 检查证据

设计稿以浏览器直接渲染。`qa-report.json`记录40张设计图和视觉规范图的尺寸、图像加载和画布越界检查；总览图用于逐组视觉复核。该检查不等同于Unity中的功能、适配或输入验证。
