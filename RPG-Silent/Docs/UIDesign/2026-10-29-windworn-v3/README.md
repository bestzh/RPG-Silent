# RPG-Silent 全界面设计 · 风痕手札 V3

2026-10-29。40 个游戏页面与关键状态，加 2 张视觉规范图；共 42 张 1920 × 1080 PNG。上一版 Synty V2 保留在相邻目录。

## 视觉方向

减少重复的方框与居中对称，让界面像冒险者随身携带的物件。苔绿皮革、暖色纸页、旧黄铜和锈红封蜡组成共用视觉；项目现有 LongCang 字体用于手写标题，Ortica 用于 SILENT 字标。

- 开始菜单：海报式字标、项目角色、手写旅人便笺与封蜡。
- 角色创建：职业缎带、角色轮廓与纸质职业注记；法师、游侠有各自的强调色。
- 行囊：错落的装备槽、纸页背包与悬浮物品说明。
- 任务手札：左右翻页、书脊和任务笔记。
- 导师：分开排布的技能卷页、圆形技能印记与手写招式名称。
- 传送：大幅目的地画面与纸质旅程票据。
- 技能规范：9 个职业、21 个独立图标，以高低错落的节点和曲线联系起来。
- 其余页面沿用同一材质与文字体系；铁匠页面使用偏暖的工坊色调，结算使用纸页回执。

## 查看文件

- `index.html`：离线设计画廊，支持目录、方向键、前后翻页和原图链接。
- `screens/`：40 个页面与状态，以及 `00-style-guide.png`、`41-skills-visual-guide.png`。
- `boards/hero-overview.png`：6 个代表页面。
- `boards/board-1.png` 至 `board-5.png`：每组 8 张的评审图。
- `boards/all-pages-overview.png`：40 个游戏页面与状态总览。
- `boards/reference-overview.png`：视觉及技能规范。
- `screen-manifest.json`：页面覆盖与功能依据。
- `source-manifest.json`：114 份素材副本的来源、GUID 和 SHA-256。
- `skill-icon-map.json`：21 个技能的图标建议及当前技能数据。
- `RESOURCE_AUDIT.md`：资源复用与尚待补齐的内容。
- `qa-report.json`、`gallery-check.json`：画板与设计画廊检查记录。

## 范围与素材说明

本版仅新增和编辑 `Docs/UIDesign/2026-10-29-windworn-v3/` 下的设计预览、PNG 与交付压缩包；未修改游戏代码、Assets、场景、预制体或游戏中的技能引用。购买、学习、强化、保存等按钮为视觉示例，排版数值不代表实际角色进度。

沿用 2026-10-29 已核实的三个资源包导入记录，详见 `import-verification.json`。本次风格调整没有重新导入资源。
