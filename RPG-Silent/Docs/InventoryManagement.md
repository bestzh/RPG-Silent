# 背包管理、整套试穿与配装

更新日期：2026-10-27。复用现有背包、预览、字体、男女装备模型和物品资源，不需要下载资源。

## 装备锁定

按 B 打开背包，选中一件防具或武器，右上“锁定装备”可保存该实例的锁定状态；再次点击解除锁定。卡片显示“已锁定”。同名另一件不受影响，锁定后仍可穿戴、强化、镶嵌或存入配装，但不能出售、单件分解或批量分解。材料不支持锁定。

## 批量分解

背包下方选择“批量分解”，点击多件防具饰品进行选择或取消。只有未穿戴、未锁定、没有宝石的实例可选。点击“分解所选”显示总件数和锻造碎片数量，再次点击确认。退出批量模式不执行分解。

每件产出仍为 `1 + 品质序号` 个碎片，六档为 1–6 个。整批只做一次保存：有一件失效、报价变化、材料存储不足或写盘失败时，全部保留，不部分分解。报价包含实例、强化、词条、宝石与锁定状态，不能用旧报价分解后来强化过的装备。服务接口也验证这些规则，不能仅绕过按钮操作。

## 多件试穿

普通模式保留原来的单件试穿。点击下方“多件试穿”进入整套草稿，从实际装备开始组合：

- 点击头部、护甲、靴子、戒指、项链替换对应预览槽，同部位只保留最后选择。
- 点击武器后，选择“试穿到武器槽 1/2”，明确修改哪个槽，并预览该槽的武器。
- “预览脱下此部位”可以预览恢复职业默认外观。
- 分类切换和查看材料保留整套草稿。界面明确标注“整套试穿 · 未装备”；属性差值包含整套的套装、宝石、强化和当前武器词条。
- “确认整套”一次性校验并保存所有槽位后更新实际模型与属性。“取消整套”、关闭背包或切换场景丢弃草稿，不改装备或存档。
- 低等级装备可预览，但任一部件等级不足时整套无法确认；实际缺件也拒绝整套更换。

涉及武器槽或当前武器改变的整套确认仅允许主城进行；副本可确认武器不变的防具整套。原有单件武器装备和 Tab 切换仍沿用拔收动画流程。

## 配装方案

背包下方“配装方案”提供 3 个固定槽。每个方案保存五件防具、两件武器的具体实例以及当前武器槽，包含空槽，后续使用各实例最新的强化和宝石数值。

- “保存当前装备”保存实际穿戴，不保存未确认的草稿；覆盖已有方案需要再次确认。
- “试穿整套”加载方案到草稿供旋转查看与修改。
- “一键换装”完整校验所有部件，保存成功后一次应用。主城仍保持武器收起；跨场景后按原有战斗规则恢复。
- “清空方案”需要再次确认，只移除方案，不删除背包物品。
- 方案不额外复制装备，也不隐式锁定装备。卖掉其中一件后，方案显示缺件并拒绝应用；这不会导致整个角色存档无法继续，可重新保存或清空方案。
